# 旅画 · Pi Agent Harness Demo

> 将旅行照片转化为可分享的叙事画面。

旅画是一个面向文旅场景的多模态生成应用原型。它以 **Pi Agent** 作为完整的 Agent Harness：由 Harness 统一承接用户输入、上下文组织、任务执行、生成状态与结果交付，并将三种旅行内容生产能力封装为可直接体验的 Agent 工作流。

当前仓库提供可本地运行的前端 Demo，用于展示产品形态、交互流程与生成结果呈现。

**在线体验：** [https://lcgf.xyz/gks](https://lcgf.xyz/gks)

**GitHub Topic：** `Guikesong`

## 核心能力

| Agent 工作流 | 用户输入 | 生成目标 |
| --- | --- | --- |
| 主角画面生成 | 人物照片 + 风景照片 | 将人物与目的地视觉元素组织成横版旅行主视觉 |
| 游客照焕新 | 一张旅行照片 | 将普通旅行照片转化为竖版艺术旅行海报 |
| 旅行足迹生成 | 人物照片 + 多个地点及照片 | 生成包含地点信息与导览视觉的旅行足迹海报 |

## Pi Agent Harness 架构

Pi Agent 在本项目中不是单一的模型调用入口，而是承载 Agent 运行过程的统一执行层：

```text
用户素材与地点信息
        │
        ▼
Pi Agent Harness
  ├─ 输入采集与素材编组
  ├─ 场景 Prompt 组装
  ├─ 多模态图像任务提交
  ├─ 任务轮询与状态管理
  ├─ 主链路与备用链路调度
  └─ 结果回传、预览与下载
        │
        ▼
旅行视觉内容
```

这套 Harness 让功能层只需要表达“要完成哪一种旅行创作”，执行层则负责组织参考图、生成提示、处理异步任务，并把生成结果交付回界面。三个功能共享同一套执行范式，同时保留各自的素材规则与叙事表达。

## 技术栈与技术选型

| 层级 | 技术选型 | 在项目中的作用 |
| --- | --- | --- |
| Agent 运行底座 | Pi Agent Harness | 统一组织素材、Prompt、工具调用、异步任务与结果交付；以 Skill、扩展和提示模板支持能力组合 |
| 多模态生成 | GPT Image 2 图像生成接口 | 基于文字提示与多张参考图，生成主角画面、旅行海报和足迹海报 |
| 前端框架 | 原生 HTML5 + CSS3 + JavaScript（ES6+） | 轻量化实现产品页面、上传交互、预览、弹窗与生成结果展示，无需构建步骤即可运行 |
| 组件机制 | Web Components / Custom Elements | `gpt-image-2-generator` 将上传、参数配置、任务提交、轮询和结果渲染封装成可复用生成组件 |
| 异步任务处理 | Fetch API + AbortController + 轮询机制 | 提交生成任务、控制请求时限、轮询任务状态，并向界面持续反馈生成进度 |
| 可靠性设计 | 主链路 + 备用链路 | 当主生成服务需要切换时，Harness 自动将任务交接到备用服务，保持用户侧的生成体验连续 |
| 数据与素材 | 浏览器 File API + Data URL + OSS 静态资源 | 管理用户本地图片、示例素材及生成结果，支持多图参考输入与下载交付 |
| 交互与体验 | CSS Variables + IntersectionObserver + 原生 DOM API | 提供统一视觉变量、渐入动效、图片放大、上传预览和响应式布局 |
| 部署形态 | 静态站点 + Nginx | 前端以静态资源方式发布，可直接通过线上 URL 访问 |

### 技术架构特点

- **轻量前端，重编排能力**：界面层保持原生、轻量和可快速部署，复杂的生成任务由 Pi Agent Harness 统一组织。
- **多图上下文输入**：不同工作流按照人物、风景、地点名称与地点图片的关系编组素材，形成面向旅行叙事的多模态上下文。
- **异步任务闭环**：从提交、状态轮询到预览和下载都在同一组件链路中完成，适合高耗时生成任务的用户体验。
- **能力可扩展**：三种工作流共用 Harness 范式，后续可通过新增 Prompt 模板、Skill 或工具扩展新的文旅内容生产场景。

## 工作流说明

### 1. 主角画面生成

用户上传人物与风景图片。Agent 将人物作为画面主体，结合多个目的地素材组织旅行叙事，输出 16:9 主视觉画面。

适合用于旅行纪念、景区互动屏、活动传播页与社交媒体封面。

### 2. 游客照焕新

用户提供一张游客照。Agent 将照片理解为视觉参考，并按预设的旅行艺术海报方向生成 9:16 画面。

适合把普通拍摄素材转化为具备传播感的旅行内容。

### 3. 旅行足迹生成

用户上传人物照，补充多个地点名称与地点图片。Agent 按输入顺序关联地点信息和参考图，生成 3:4 的城市旅行足迹海报。

适合用于路线回顾、城市打卡、旅游攻略与行程留存。

## 前端实现

- 原生 HTML、CSS、JavaScript，适合快速验证产品体验
- 自定义图像生成组件负责素材上传、任务提交、轮询与结果展示
- 共享交互层提供示例素材、上传预览、动效、放大查看与下载入口
- 三个页面复用统一的 Agent 调用模式，并分别维护场景 Prompt 与画幅配置

## 本地运行

在项目根目录执行：

```powershell
./start-lan-preview.cmd
```

然后访问 [http://127.0.0.1:8080/index.html](http://127.0.0.1:8080/index.html)。

也可以使用 Python 启动静态服务：

```powershell
py -3 -m http.server 8080 --bind 127.0.0.1
```

## 页面入口

- `index.html`：产品首页与三类工作流入口
- `hero.html`：主角画面生成
- `reframe.html`：游客照焕新
- `footprint.html`：旅行足迹生成
- `image-generator-demo.html`：图像生成组件示例

## 迭代方向

这个 Demo 已经验证了“旅行素材 → Agent 编排 → 叙事画面”的完整体验闭环。后续可以围绕 Pi Agent Harness 继续扩展：

- 将场景 Prompt 配置化，支持景区主题与品牌视觉的快速切换
- 接入用户会话与任务记录，沉淀个人旅行内容资产
- 补充生成结果的精选、编辑、分享与传播链路
- 为文旅活动、酒店、景区和城市营销提供可定制的 Agent 工作流
